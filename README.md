# The Curated Room Co.

A minimalist, modern Filipino-inspired website showcasing curated home design ideas and affiliate product recommendations.

## 🌿 About
The Curated Room Co. is focused on:
- Budget-friendly house designs
- Modern Filipino-style inspirations
- Curated affiliate picks for timeless living spaces

## 🛋 Features
- Clean, minimalist homepage
- "Shop My Picks" section with design categories
- Affiliate product listings with disclosure
- Responsive layout for desktop and mobile
